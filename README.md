# G-SmartClass

G-SmartClass is an education application project. The public repository contains a modular Python desktop implementation and supporting components for related application surfaces.

## Current implementation
- Desktop application built with Python and PySide6
- Modular separation across controllers, models, repositories, services, and views
- Firebase-related integration code
- Additional web and mobile directories are present; implementation status varies

## Technology
- Python
- PySide6
- Firebase
- HTML, CSS, and JavaScript project components

## Repository structure
The repository is organized by application area and feature modules. Key directories include desktop, backend, web, and mobile.

## Setup
1. Install Python 3.10 or newer.
2. Create and activate a virtual environment.
3. Install dependencies listed in the desktop requirements file.
4. Configure Firebase credentials locally. Do not commit service-account keys or private credentials.
5. Follow the desktop entry point and project configuration to run it.

## Project status
This repository is under development. This README describes the public source tree; it does not claim every desktop, web, or mobile component is production-ready. Run the application and verify relevant flows before relying on a feature.
